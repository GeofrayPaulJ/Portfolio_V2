### Web Architecture & Full-Stack Deployment
Architected and deployed production-grade web infrastructure, transitioning from institutional to sovereign commercial assets.
* **Institutional Deployment:** Engineered and deployed the official web platform for the Sudha Gopalakrishnan Brain Centre (SGBC).
* **Frontend Ecosystems:** Developed a proprietary library of 7 highly optimized React.js templates, designed to drastically reduce time-to-market for future B2B SaaS deployments.
* **Portfolio Iteration:** Currently iterating on a second-generation architectural portfolio, utilizing Next.js and Edge Functions to integrate serverless Retrieval-Augmented Generation (RAG) capabilities to automate client vetting.

### Enterprise Automation Pipelines 
Engineered high-complexity automation scripts and data extraction pipelines. These technical assets were deployed as premium solutions for international clients via a managed freelance partnership profile.
* **SEC EDGAR Institutional Spyglass:** Built a Python-based scraper navigating the SEC's complex XML document trees. Engineered automated handling of strict rate limits (10 req/sec) to extract and format 13F institutional portfolio data into structured analytics.
* **Stripe Accounting Exporter:** Developed an API bridge to resolve complex financial reconciliation for e-commerce clients. Utilized cursor-based pagination against the Stripe `balance.transactions` endpoint to isolate fees, refunds, and rolling reserves into audit-ready ledgers.
* **Dynamic Lead Reconnaissance (Google Maps):** Architected a robust Selenium-based web scraper to extract high-value B2B data. Engineered solutions to bypass dynamic React application rendering and infinite-scroll pagination to reliably harvest local business intelligence.
* **OpenAI x No-Code Middleware Connector:** Deployed a FastAPI cloud function acting as an asynchronous bridge for platforms like Bubble.io. The middleware successfully intercepts OpenAI API requests, manages long-running assistant threads, and returns payloads via webhook to prevent standard browser timeouts.
